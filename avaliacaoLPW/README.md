# FoodExpress 🍕

Projeto desenvolvido para a disciplina de **Laboratório de Programação Web**, com o objetivo de criar um site para uma pizzaria fictícia chamada **FoodExpress**.

## 📌 Sobre o projeto

O FoodExpress é um site institucional de uma pizzaria. Ele apresenta o cardápio, informações sobre horários de funcionamento e valores nutricionais, além de um formulário para reservas de mesas e contato.

O projeto foi desenvolvido utilizando HTML5 e CSS3, com foco na organização do conteúdo, na navegação entre páginas e na adaptação do layout para diferentes tamanhos de tela.

## 🖥️ Páginas do site

- **Cardápio (`index.html`):** apresenta as opções de pizzas, bebidas e sobremesas, com descrições e preços.
- **Horários e Nutrição (`horarios.html`):** informa os horários de atendimento no salão e delivery, além de apresentar uma tabela com valores nutricionais aproximados de alguns produtos.
- **Reservas e Contato (`reserva.html`):** disponibiliza um formulário para preenchimento de dados pessoais, solicitação de reserva, escolha do ambiente e envio de mensagens.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas e criação dos elementos do site.
- **CSS3:** estilização, organização do layout e responsividade.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador de internet.
4. Utilize o menu de navegação para acessar as demais páginas.

Não é necessário instalar dependências ou configurar um servidor para visualizar as páginas.

## 📱 Responsividade

O layout utiliza recursos de CSS, como Flexbox, Grid e Media Queries, para adaptar a apresentação do conteúdo a diferentes larguras de tela, incluindo dispositivos móveis, tablets e computadores.

Este projeto foi desenvolvido como atividade prática da disciplina de **Laboratório de Programação Web**, aplicando conceitos de estruturação de páginas com HTML e estilização com CSS.
